BRAIN.COM.UA DATA SNAPSHOT
==========================

This directory contains the validated reference output generated by the parsing pipeline.

FILES
-----
products.csv
    UTF-8 CSV export of the normalized PostgreSQL Product records.

    Reference rows:
    - requests_bs4  -> U0961530
    - selenium      -> U0854689
    - playwright    -> U0854689

    JSON-backed fields such as image_urls and characteristics are serialized as JSON strings.

database.dump
    PostgreSQL custom-format backup created with pg_dump.
    It can be inspected with:

        pg_restore --list results/database.dump

REGENERATE
----------
Run the three parsers first, then create fresh artifacts:

    python modules/1_parse_requests_bs4.py
    python modules/2_parse_selenium.py
    python modules/3_parse_playwright.py
    python modules/4_export_csv.py
    python modules/5_dump_database.py

VALIDATE
--------
Run:

    python qa/runtime_validation.py

A successful validation ends with:

    'status': 'passed'

NOTES
-----
The included snapshot reflects Brain.com.ua product data at the time of the reference run.
Prices, review counts, images, and characteristics may change when the source website is updated.
